# 江戶大亂鬥

江戶時代風格的網頁動作遊戲（紅白機像素風），兩人透過 Tailscale 連線合作。

目前內容：一個關卡（街道，5 波敵人，最後首領四郎）、雙人合作、鍵盤與手機觸控。

## 啟動（在當伺服器的電腦上）

需要 [Node.js](https://nodejs.org) 20 以上。Windows / Mac / Linux 步驟相同：

```bash
npm install
npm run build
npm start
```

終端機會印出網址，例如 `http://100.101.102.103:8080/`，那是這台電腦的 Tailscale 位址。

## 跟遠方朋友玩

1. 兩人都安裝 [Tailscale](https://tailscale.com/download) 並登入。朋友不在你的帳號下的話，到 Tailscale 管理頁面把這台電腦「分享」給他（Share），或邀請他加入你的 tailnet。
2. 你先啟動伺服器（上面三行指令），用終端機印出的網址開啟遊戲，按「建立房間」。
3. 把網址列上的連結（結尾是 `#ABC123` 房間代碼）傳給朋友。他用瀏覽器開啟就會自動加入；也可以手動輸入代碼。
4. 手機用同一個網址即可，需先在手機上開啟 Tailscale。

房間最多 2 人，第二位可以隨時中途加入。畫面右上角會顯示延遲。

## 版本與自動更新

- 選單最下方會顯示版本（版本號＋提交編號＋日期），伺服器啟動時也會印出。
- `npm start` 在啟動伺服器前會自動：
  1. 從 GitHub 更新到目前分支的最新提交。只會做「快轉」更新；本機有改過的檔案、離線、或分支與遠端分歧時會略過，不會覆蓋你的東西。
  2. 套件檔有變動時重新 `npm install`，程式有變動時重新建置。
  任何一步失敗都只印出提示，仍會用現有版本啟動。
- 不想更新：`NO_UPDATE=1 npm start` 或 `npm run start:offline`。只更新不啟動：`npm run update`。
- 伺服器開著的時候不會自己更新，要更新請重新啟動（`Ctrl+C` 再 `npm start`）。
- 朋友的瀏覽器如果載到舊版頁面，連進房間時會發現版本和伺服器不同，自動重新載入一次。
- 自動更新等於「執行 GitHub 上那個分支的程式碼」，所以只會跟隨你 clone 的那個分支。

## 安全設計

- 預設只綁定 `127.0.0.1` 和 Tailscale 網卡（100.64.0.0/10），區域網路與公網都連不到。找不到 Tailscale 時會在終端機警告。
- 想自己指定位址：`HOST=100.x.y.z npm start`（可用逗號分隔多個）。`HOST=0.0.0.0` 會開放所有網卡，不建議。
- 埠號用 `PORT=9000 npm start` 修改，預設 8080。
- 伺服器會檢查 WebSocket 的 Origin、限制封包大小與頻率、限制連線數與房間數；房間代碼是隨機 6 碼。
- 建議用一般使用者帳號執行，不要用管理員／root。若這台電腦上還有其他重要服務，可以考慮用 Docker 隔離。

- **雙持**：手上拿著竹刀或光劍時，靠近地上另一把竹刀或光劍按 A，會撿到另一隻手（兩把各有自己的耐久，血條下面顯示「光劍 30 + 竹刀 18」）。揮砍時左右手輪流，B 先丟副手那把再丟主手；主手壞掉時副手會換過來，被打倒時兩把都會掉。雙持和「雙劍」一樣，連砍 4 下就是炫風斬，結束時兩把平分 8 點耐久。（拿著刀劍、腳邊剛好又有另一把刀劍時，按 A 會先撿起來而不是揮砍。）
- 雙劍的 **炫風斬**：連續砍 4 下（每一下要在上一下收招後 1/3 秒內接上，不用打中人）；第 4 下不再是揮砍，主角雙手張開、像陀螺一樣旋轉 10 秒，兩邊的敵人每 8 格被砍一次（每下 4 點，把敵人釘在原地，最後一下打飛）。旋轉時**可以自由移動**，被打只會扣血、不會被打斷（致命的一擊除外），期間不能跳、不能出別的招，也不能放大絕（光束）。數字在 `src/shared/weapons.ts` 的 `TWIN`。
- 打擊手感：每打中敵人一下，敵人身上就彈出傷害數字（會放大、飄起、在白色與黃色間閃動）；有 10% 機率**爆擊**，傷害 ×2，數字放大變紅黃閃爍、上面多一個「爆擊」，畫面會震一下並閃光。畫面下方有「攻擊 N」連擊計數（P1 在左、P2 在右），每打中一下就跳一下，數字越大顏色越燙（白、黃、橘、紅）；停手約 1.3 秒歸零，主角被打到也歸零。百裂拳、龍捲風腳、炫風斬、多段招式每一下都算。使出昇龍拳、百裂拳、龍捲風腳、炫風斬和六個特殊技時，主角頭上會冒出對話框喊出招式名稱。數字在 `src/shared/feel.ts`（`CRIT`、`COMBO`、`CRY`）。
- 全螢幕加寬 demo（`/?wide`，只有單人練習）：畫面撐滿視窗，按鈕半透明疊在上面，戰場寬度隨視窗比例變寬（最窄 256、最寬 480；開始遊戲時決定），敵人從更遠的邊界進場，東海道跟著變長、將軍仍在最後一屏；溫泉關背景只有 256 寬，兩側用鏡射補上。連線房間仍是固定 256，因為同房的人必須看到同一個戰場。手機測試可加 `&touch`。
- 集氣（悟空）：**空手**（沒拿武器、沒抓著敵人）站著不動按住 A 超過 3 秒，主角開始集氣（藍白光、地上光圈、碎石飄起、畫面微震，頭上喊「啊啊啊啊——！」）；按滿 10 秒頭髮變金色、全身金光（喊「金光覺醒！」），之後 30 秒**血量上限和魔力上限都變兩倍**（血量當下也跟著加倍），藍條改成顯示金光剩餘時間。移動、按 B、放特殊技、被打到或放開 A 都會從頭來過；金光期間不能再集氣，倒下時金光立刻消失。數字在 `src/shared/feel.ts` 的 `CHARGE`。
- 空手跑步招式（手上沒有武器時才會出）：跑步中按 A 是 **百裂拳**，連續打出 20 拳，發動中不會被打斷（照樣會受傷，但不會被打退）；跑步中按 B 是 **龍捲風腳**，主角微微飛起、水平旋轉往前飄，前後都打得到，最後一腳把敵人踢飛，同樣不會被打斷。拿著武器時不會出這兩招（跑步中按 A 就是一般的武器攻擊）。
- 特殊技：A / B 按鈕上方有六顆特殊技按鈕（鍵盤 `1`～`6`），一開始全部都能按；按下去就發動，該技能進入自己的冷卻，其他技能不受影響。**冷卻秒數 = 技能能力 ÷ 90**（能力值寫在 `src/shared/specials.ts`），按鈕上的暗色扇形與數字是剩餘冷卻。血條上方的六個小方塊是各特殊技的狀態：亮色＝可以用，暗色＝冷卻中。血條下面的藍條只用來顯示持續中特殊技的剩餘時間（爆氣、聖盾時為金色）。倒地、受傷、被抓、死亡時不能用；龜甲砲、聖盾還需要站在地上。六個特殊技：

  | 特殊技 | 效果 | 能力 | 冷卻 |
  | --- | --- | --- | --- |
  | 龜甲砲 | 短暫蓄力後發出持續約 6 秒的光束，發射期間不能移動，但無敵 | 1800 | 20 秒 |
  | 連拳彈 | 連發 10 顆拳氣彈，可以邊移動邊發射；被打倒就中斷 | 1350 | 15 秒 |
  | 光環 | 腳下出現金色魔法陣（固定在施放的位置，持續 10 秒），站在陣裡的我方每秒回 10% 血量，站滿全程剛好補滿；走出陣就不補，隊友站進來也會補 | 2700 | 30 秒 |
  | 爆氣 | 金色氣焰包住全身，所有傷害 ×2，持續 20 秒 | 3600 | 40 秒 |
  | 聖盾 | 聖光化成羅馬大盾：受到的傷害變成 1/3、不會被打退，但不能走動、不能跳，持續 10 秒 | 2700 | 30 秒 |
  | 天雷萬鈞 | 從天空召喚閃電，連續 10 秒對整個戰場落雷（每 0.1 秒一道，七成會劈向畫面內的敵人，其餘隨機落在地上），期間主角可以自由移動、戰鬥；只傷敵人 | 7200 | 80 秒 |

  冷卻從發動那一刻開始算，包含效果持續的時間。
- 無限輪迴：關卡不會結束。東海道打倒大將軍和最後一波敵人後，約 2.5 秒會接到 **溫泉關**，守住關口後再接回東海道起點（黑幕淡入並顯示關名與「第 N 周」）；命數、分數、**手上的武器**、特殊技冷卻都會保留。**換關時地上沒撿的武器全部消失**（1UP 和補品不是武器，會留在下一關起點等你撿）。只有兩人命都用完（GAME OVER）才會整個重來。
- 溫泉關（一夫當關）：畫面鎖定在一個畫面，能走的沙路只有東海道的約 40% 深（`src/shared/onsen.ts`）。開場是一段不能操作的過場：敵方派使者來勸降，主角只回「。。。」，一腳把使者踢進前景的溫泉池，然後開打。敵人是 50 名**精英**（血量 ×1.5、攻擊 ×1.3，腳下有紅圈；混編上層武士、忍者、三郎），從右邊源源不絕補位，畫面上同時最多 5 名（每周多 1 名）；殺到第 35 名時**叛徒**從左邊衝進來並大喊「讓他下課！」（血量 ×3，紫圈，上方有血條；倒下時**一定掉雙劍**），一共 50 名（含叛徒）。全部倒下就守住了，停一下接回東海道、周目 +1。雙人可以一起守。想看效果可以用 `/?stage=onsen` 直接從溫泉關開始單人練習。背景圖是 `art-src/bg-onsen.png`，用 `python3 tools/build_onsen.py` 縮成遊戲大小（把兩道圍欄中間的沙路拉高，變成能打架的範圍）。
- 越打越難：每跑完一周，怪物等級 +1（第 1 周是 Lv.1），每一波敵人多 1 隻（大將軍不會變多），血量與攻擊力各 +10%（以原本數值計，第 2 周 ×1.1、第 3 周 ×1.2…，忍者的飛鏢也算）。畫面上方會顯示「第 N 周　怪 Lv.N」。
- 敵人的光環：血量低於 60% 的敵人，站著沒在打人時會隨機在腳下放出魔法陣幫自己補血（同樣每秒 10%，陣只維持 4 秒，共補 40%；施放者會站在陣裡不動，所以可以趁機攻擊打斷；陣裡的其他敵人也會一起補。每隻敵人 10 秒才能放一次，被打趴或僵直時不會放）。參數在 `src/shared/specials.ts` 的 `ENEMY_HALO`。
- 補品：每隻敵人倒下有 10% 機率留下補品（紅藍小瓶），走過去就會撿，血條上限與 mana（藍條）上限各 +10，同時補 10 血。上限會一直保留到 GAME OVER，血條與藍條也會隨之變長。目前 mana 上限只是數字，還沒有其他用途。
- 練習：單人練習的網址加上 `?weapon=1`～`5` 可以直接拿著武器開始，例如 `http://…:8080/?weapon=3`。
- 倒地的敵人：靠近按 A 舉起；舉著時 A 揮敵、B 投擲；在倒地敵人旁按 A+B 踩敵。
- 昇龍拳：剛跳起的瞬間按 A。
- 兩人之間不會互相傷害。每人 3 條命。

## 美術

遊戲讀取 `assets/manifest.json` 裡的角色圖；沒有對應圖或動作時，退回內建的像素角色。目前 `assets/gen/` 是由 AI 出圖轉出的四個角色（主角與三種換色的敵人）。

### AI 出圖 → 遊戲素材

1. 用圖像模型出動作表（3x2 格、純色背景、角色朝右、同一個人），存成 PNG 或 JPG 放進 `art-src/`。
2. 在 `tools/build_sprites.py` 最上方的 `SHEETS` 登記檔名、格數與每格的動作名稱。
3. 執行：

```bash
pip install pillow numpy
python3 tools/build_sprites.py --preview preview.png
```

工具會自動去背、切格、縮成遊戲大小、對齊腳底、限制調色盤，並輸出四個換色角色與 `assets/manifest.json`。`preview.png` 可以快速檢查每一格。

目前已有的動作：待機、走路、跑步、跳（上升、頂點、下降、落地緩衝）、出拳、踢、跳踢、百裂拳、龍捲風腳、昇龍拳、受傷、被打飛（空中兩種姿勢）、倒地、起身、抓起／扛著／揮舞敵人、丟、踩、撿東西、龜甲砲（蓄力、發射、收招）、連拳彈發射，以及五種武器（木棒、竹刀、石頭、光劍、AK-47）各自的持握（加特靈機槍用程式畫，沒有專屬動畫；遠古長弓、鬼火雙頭薙刀、雷切、霸王槍四把神兵各有專屬的持握、走路、跑步、跳和攻擊動作（`art-src/sheet-bow.jpg`、`sheet-naginata.jpg`、`sheet-raikiri.jpg`、`sheet-spear.jpg`；霸王槍那張的姿勢不是整齊的格子，所以用形狀分開，並多一個衝刺和一個旋轉姿勢），掉在地上的圖和靈氣箭用 `tools/build_icons.py` 從 `icons-bow.jpg`、`icon-naginata.jpg`、`icon-raikiri.jpg`、`icon-spear.jpg` 裁出；雙劍有專屬的持握、走路、跑步、跳、揮砍和炫風斬動作，來源是 `art-src/sheet-twin.jpg`，炫風斬那一格太貼近隔壁所以另外裁成 `sheet-twin-whirl.jpg`；用「竹刀＋光劍」這種兩把拼起來的雙持仍然是程式畫的）、走路、跑步、跳與攻擊。敵人有三郎（雜兵，換色版）、忍者、上層武士（揮刀）和大將軍（首領，揮鐵扇槌）；後三者都有專屬動畫。上層武士和大將軍由 `tools/build_enemies.py` 產生，各自從自己的圖抽出調色盤，大將軍用較大的格子。忍者會在中距離丟手裏劍（只打玩家，被盾擋住傷害會減少）。背景會隨著關卡推進從白天慢慢轉成黃昏。尚缺：受傷的變化（輕擊、重擊、被背後打、持武器被打）。

背景是三層視差捲動：遠景（天空、富士山、遠山，捲動最慢）、中景（江戶街屋，後段接東海道松林與鳥居）、地面（路面磚，隨鏡頭）。來源圖在 `art-src/bg-*.jpg`，用 `python3 tools/build_bg.py` 去背、縮成遊戲大小、限制調色盤，輸出 `assets/gen/bg_*.png` 並寫入 `manifest.json` 的 `_backdrop`；沒有這些圖時會退回內建的簡易背景。

### 使用自己的圖

在 `assets/` 放圖並寫好 `manifest.json`（格式見 `assets/manifest.example.json`）。每個角色是一張格狀圖：`w`/`h` 是單格大小，`ox`/`oy` 是腳底中心在格內的位置，`anims` 把狀態名對應到格子編號（由左到右、由上到下，從 0 起算）。動作可寫成 `{"frames": [..], "ticks": [..], "loop": true}` 指定每格停留的遊戲刻數（60 刻 = 1 秒），或直接寫格子編號陣列。

- 角色代號：`ichiro`（一郎，主角）、`jiro`（二郎，P2）、`saburo`（三郎，雜兵）、`ninja`（忍者）、`bushi`（上層武士）、`shogun`（大將軍，首領）。
- 可用狀態名：`idle walk run jump punch kick airkick dash upper hurt down getup swing throw lift hold held stomp dead pick holdswing`。缺少的狀態會退回 `idle`。
- 重新整理頁面即可，不用重新建置。
- `assets/` 內除了 `manifest.json` 與 `gen/` 以外的檔案不會被 git 上傳；不是自己創作的素材請只供私下使用，不要公開散布。

## 開發

```bash
npm run dev:server   # 遊戲伺服器（8080，自動重啟）
npm run dev:client   # Vite 開發伺服器（5173，代理到 8080）
npm test             # 單元測試 + 伺服器測試 + 機器人通關測試
npm run typecheck
```

結構：`src/shared` 是遊戲規則（固定 60Hz、亂數可重現），伺服器與單人模式共用；`src/server` 是房間與連線；`src/client` 是畫面、輸入與連線。關卡與敵人數值在 `src/shared/stage.ts`、`src/shared/defs.ts`。

連線方式：伺服器執行遊戲並每秒廣播約 30 次狀態，玩家只傳按鍵；朋友那端的畫面會比你晚約「延遲 + 90ms」。若覺得操作黏，下一步可加客戶端預測或回滾網路碼（遊戲規則已設計成可重現，不用大改）。

## 背景音樂

沒有音檔時，音樂由程式當場合成（`src/client/synth.ts`）：三味線和箏是撥弦（Karplus-Strong 弦模擬），太鼓是下沉的低頻加噪音，尺八是帶氣聲和顫音的長音，音階用日本的「陰音階」（D、降E、G、A、降B）。四首曲子（選單、東海道、大將軍、溫泉關）寫在 `TUNES` 裡，一小節 16 格，改字串就能改旋律。

要換成真的音樂，把循環音檔（`.mp3` 或 `.ogg`）放進 `assets/music/`，有檔案就用檔案（不用重新打包，重新整理即可）：

| 檔名 | 播放時機 | 找不到時 |
|---|---|---|
| `menu` | 主選單 | 用 `tokaido` 的檔案，都沒有就合成 |
| `tokaido` | 東海道 | 合成 |
| `shogun` | 大將軍在場上時 | 用 `tokaido` 的檔案，都沒有就合成 |
| `onsen` | 溫泉關 | 用 `tokaido` 的檔案，都沒有就合成 |

用 Web Audio 無縫循環，換場景時淡入淡出（約 1.2 秒）。瀏覽器要等玩家第一次點擊或按鍵才能出聲；右上角的 ♪ 可以靜音（記在瀏覽器裡）。

## 打擊音效

音效也是程式合成（`src/client/sfx.ts`，沒有音檔），跟音樂共用同一個 ♪ 靜音鍵。來源有兩個：模擬送來的事件（拳腳命中輕／重、盾牌擋下、爆擊多一聲清脆的響、雷切放電、天雷、水花、金光覺醒、萬箭齊發的鑼鼓加箭雨聲），以及每個角色的動作狀態（出拳／踢／揮砍的破風聲、弓弦、步槍和加特靈槍聲、跳、落地、撿東西、龜甲砲蓄力與發射、集氣、旋轉類招式每圈的風聲、光環／聖盾等加成開啟）。同一刻太多聲音會限流（0.1 秒內最多約 12 個，萬箭齊發的密集命中每 35 毫秒只出一聲），整體再過一個限幅器避免爆音。
